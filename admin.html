💬 Live Chat — Tawk.to

Đăng ký miễn phí tại tawk.to → Dashboard → Administration → Chat Widget → copy 2 mã bên dưới.
Sau khi lưu, thêm script vào cuối index.html, faq.html:
s1.src='https://embed.tawk.to/[PropertyID]/[WidgetID]'

📨 EmailJS — Gửi email tự động

Đăng ký tại emailjs.com (miễn phí 200 email/tháng) → Account → API Keys.
💡 Dùng MailApp (Google Apps Script) là free không giới hạn — EmailJS là backup cho trường hợp cần gửi từ browser.
